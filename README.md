# Grocery Shopping Application

A full-stack grocery shopping application built using the **MERN stack**.

## Features

* User registration and login
* Product browsing
* Categories and subcategories
* Cart and wishlist
* Address management
* Order placement
* Razorpay payment integration
* Admin product and order management
* Forgot/reset password

## Tech Stack

* React.js
* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT
* Razorpay
* Nodemailer

## Application Flow

```text
React.js
   ↓
REST APIs
   ↓
Node.js + Express.js
   ↓
MongoDB
```

## Setup

```bash
git clone https://github.com/NikhiDevadiga/Grocery-Shopping-Application.git
npm install
npm run dev
```

Create a `.env` file with the required database, JWT, Razorpay and email credentials.

> Never commit `.env` or API keys to GitHub.
